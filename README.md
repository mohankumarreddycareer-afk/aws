
# AWS CI/CD Pipeline Project

## Project Overview
This project demonstrates automated web application deployment using GitHub, Jenkins, and AWS EC2.

## Technologies Used
- AWS EC2
- Linux
- Git and GitHub
- Jenkins
- HTML

## Project Architecture
Developer -> GitHub -> Jenkins -> AWS EC2 -> Web Application

## Project Workflow
1. Create an HTML web application.
2. Upload source code to GitHub.
3. Configure Jenkins to access the GitHub repository.
4. Create a Jenkins CI/CD pipeline.
5. Deploy the HTML application to the AWS EC2 web server.
6. Verify the application in a web browser.

## Application File
- index.html

## Expected Result
The HTML website should be accessible through the web server after successful deployment.

## Learning Objectives
- Understand Git and GitHub workflows.
- Configure Jenkins pipelines.
- Automate application deployment.
- Practice AWS EC2 server administration.
